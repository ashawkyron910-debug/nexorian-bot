NEXORIAN.CC DISCORD BOT

Setup:
1. Install Node.js LTS.
2. Run: npm install
3. Create .env from .env.example and put your Discord bot token there.
4. Run: npm start

PM2:
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save

Commands:
!ping
!server

Never commit or share your .env or Discord bot token.
